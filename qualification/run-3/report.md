# Desktop implicit-selection observation

Date: 30 September 2026. Source baseline: `938a4a1`. The skill and its metadata remained unchanged throughout this run.

## Result

Desktop discovery and implicit selection are confirmed in this observed environment. The parent desktop chat's available-skills catalogue now included `product-sense` at its installed user path. A fresh projectless desktop chat, titled **Product idea assessment**, received a normal product question without naming the skill, supplying its description or pointing to its files.

The new chat announced that it would use Product Sense, then read the installed entrypoint and discovery, shaping and output references. Native command records show successful reads with untruncated output. It also read the installed Superpowers entrypoint. The five model commands were all read-only `cat` operations; no edits, external contacts or experiments were performed.

The assessment passed four of five declared criteria. It separated stated interest from demonstrated demand, labelled supplied facts and hypotheses, proposed a bounded learning step, and supplied a prototype/park/reshape condition. It **failed the requested word limit**: 187 words against a maximum of 180, using the same whitespace-counting convention as the earlier runs.

Implicit selection passed; complete task compliance did not. The word-limit failure is retained as evidence.

## Method and evidence

One new desktop chat was created after the parent user approved the recommended fresh-chat check. It used the app's configured model with no override and a neutral projectless directory, separate from this repository and its qualification files. No parent conversation history, rubric or skill instructions were supplied. Native creation wrapped the ordinary prompt in a delegation envelope containing the source chat identifier; that wrapper is preserved in the recorded output.

The chat completed one turn in 83.635 seconds. No follow-up message or second model sample was sent. It remains a user-owned chat.

## Limits and decision

This establishes discovery and one implicit selection in the current desktop environment. It does not establish repeatability, behaviour without the other installed skill instructions, visible picker rendering, real-user outcomes or improvement over an ordinary model response. The installed Superpowers guidance encourages using applicable skills, so the result applies to this combined environment.

Keep the current Product Sense guidance. Native discovery, explicit invocation and desktop implicit selection have now each been observed. Treat strict word limits as a known task-compliance weakness from this sample; it does not by itself justify a skill rewrite. Further qualification should target recurring failures found during ordinary use, rather than extending this run beyond its declared budget.
